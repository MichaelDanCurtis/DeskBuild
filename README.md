# DeskBuild
Building components for my next amazing desk 

## Components

- [`rising-knob-panel/`](rising-knob-panel/) — a 3D-printed mechanism that raises a 1.5" ESP32-S3 knob display
  out of a wood panel when a hand comes near and sinks it flush when the hand leaves.
  Its ESP32-S3 firmware is in [`rising-knob-panel/firmware/`](rising-knob-panel/firmware/).
